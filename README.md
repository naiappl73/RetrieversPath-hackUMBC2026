# HACKMAP-hackUMBC
hackUMBC HACKMAP project with Anaiah, Martin, Paul

## Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/naiappl73/HACKMAP-hackUMBC.git
cd HACKMAP-hackUMBC
```

### 2. Create virtual environment
```bash
python -m venv .venv
```

### 3. Activate the virtual environment
- **macOS / Linux**:
  ```bash
  source .venv/bin/activate
  ```
- **Windows**:
  ```cmd
  .venv\Scripts\activate
  ```
  *(or in PowerShell: `.\.venv\Scripts\Activate.ps1`)*

### 4. Install dependencies
```bash
pip install -e .
```
*(or using `uv`: `uv sync`)*
